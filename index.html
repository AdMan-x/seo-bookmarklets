SEO Bookmarklets

Trois bookmarklets pour récupérer rapidement les données d'une SERP. Glissez un bouton dans votre barre de favoris, puis cliquez dessus depuis une page.

Exemple : ceci est un bouton à glisser

Un clic sur cette page ne fait rien : il faut d'abord glisser le bouton dans la barre de favoris.

Les bookmarklets

Get All Titles

Copie les titres (h3) de la page, un par ligne.

All URL

Copie les URL des résultats, une par ligne.

Title

Copie le title de la page.

Installation

1. Affichez la barre de favoris : Ctrl+Maj+B (Windows, Linux) ou Cmd+Maj+B (macOS).
2. Glissez le bouton voulu dans la barre.
3. Ouvrez une page de résultats, cliquez sur le favori, le contenu est copié.

Limites

Get All Titles ramasse tous les h3 : sur Google, cela inclut les annonces et le bloc de recherches associées.
All URL est optimisé pour Google, avec un repli pour Bing et DuckDuckGo.
